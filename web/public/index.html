Tab Audio Exporter

タブで鳴っている音を MP3 (192kbps) で書き出します

使い方
  1. 音を録りたいタブを別のタブで開いておく（このページは録音用）
  2. 「録音開始」→ 共有ダイアログで「Chromeタブ」を選び、対象タブを選択
  3. 「タブの音声も共有」にチェックを入れて「共有」
  4. 録りたい音を再生 → このタブに戻って「停止」→ MP3を保存
※ macOS ではシステム音声は共有できません。「Chromeタブ」のみ音声付きで共有できます。
